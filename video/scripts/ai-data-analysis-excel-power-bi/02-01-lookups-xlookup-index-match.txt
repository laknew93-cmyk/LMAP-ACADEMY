Welcome to AI for Data Analysis, module 2, lesson 1: Lookups: XLOOKUP, INDEX MATCH and VLOOKUP.

Lookups are the formulas that join one table to another. Think of pulling a product's G S T rate into a sales sheet, or a sales owner's region into a leads list. In this lesson, we'll cover XLOOKUP, INDEX MATCH and VLOOKUP, with AI as your guide.

Let's start with the problem lookups solve. Pink City Fabrics has two sheets. The Sales sheet has one row per invoice line, with invoice number, date, item code, quantity and amount. For example, invoice P C F 1041 sold two units of item S R 102 for forty-two hundred rupees. The Products sheet has one row per item, with item code, item name, category and G S T rate. For example, S R 102 is a Bandhej Silk Saree, in the Sarees category, at five percent G S T. Both sample tables are in the lesson notes below this video. Now, you want the category in the Sales sheet so you can summarise by category. That's a lookup. You find the item code in Products, and return the category from the same row.

XLOOKUP is the modern default. It's available in Microsoft 365, Excel 2021 and later, and Google Sheets. The formula is equals XLOOKUP, then C2, then the item code column in Products, then the category column in Products, then "Not found". Read it like this: look for C2 in the item code column of Products, return the matching value from the category column, and show "Not found" if there's no match.

The full syntax has six arguments. The lookup value, the lookup array, the return array, and then three optional ones: if not found, match mode, and search mode. Match mode zero, the default, means exact match. Search mode minus one searches from the bottom up, which is handy for "latest entry" problems.

So why does XLOOKUP beat VLOOKUP? There are four reasons. First, the return column can be to the left of the lookup column. Second, inserting a column doesn't break it, because there's no column index number to go stale. Third, exact match is the default. VLOOKUP's default is approximate, and that's a classic source of wrong answers. And fourth, it has built-in "not found" text, so you don't need to wrap it in IFERROR.

In Excel 365, XLOOKUP can even return several adjacent columns at once. If your return array covers columns B to D of Products, the result spills item name, category and G S T rate into three cells. If the cells to the right aren't empty, you'll see a SPILL error. Just clear them, and it works.

Now, INDEX MATCH, for older Excel. If your office uses Excel 2016 or 2019, XLOOKUP shows a NAME error. The classic equivalent is INDEX with MATCH. It works in two parts. MATCH finds the row position of the item code in the Products item code column. The third argument, zero, means exact match, and you should never leave it out. Then INDEX returns the value at that position in the category column. To handle missing codes, wrap the whole thing in IFERROR with "Not found". The formulas are in the lesson notes below the video.

What about VLOOKUP? Know it, but avoid it for new work. You'll inherit files full of VLOOKUP, so you need to be able to read it. A typical one is equals VLOOKUP, then C2, then Products columns A to D, then 3, then FALSE. This looks for C2 in the first column of A to D, and returns the third column, which is category. The FALSE forces an exact match. Here's the danger. If someone inserts a column in Products, that 3 now points at the wrong data, and nothing warns you.

Next, two-condition lookups. LeadLoop's target sheet has one row per owner and month. Say you want to fetch Priya's target for October. In Excel 365 or Google Sheets, there's an XLOOKUP trick. You multiply two conditions together, owner equals B2, and month equals C2. That creates an array of ones and zeros, which is one only where both conditions are true. Then XLOOKUP looks for the first one, and returns the target. The code is in the lesson notes below the video. On large sheets, use exact ranges, like rows 2 to 500, rather than whole columns, to keep it fast.

There's also a simpler, version-proof alternative: a helper column. In the Targets sheet, add a column that joins the two keys with a separator, so you get something like "Priya, pipe symbol, Oct 2026". Then do a normal lookup on the same joined key from your other sheet. Helper columns are easy for colleagues to understand, so don't be shy about using them.

Now, why do lookups fail, and what should you ask AI? Most N A errors come from one of four causes. One, extra spaces, like "S R 102" with a trailing space. The fix is to wrap it in TRIM, or clean the source. Two, a number stored as text, so 1041 the number doesn't match 1041 the text. Convert it with VALUE, or use Text to Columns. Three, the key is genuinely missing, for example a new item that isn't in the master yet. Add it to the master, and use the if not found argument. And four, approximate match, like a VLOOKUP without FALSE. Add FALSE, or switch to XLOOKUP. There's a table of all four in the lesson notes.

When a lookup fails, give the AI the specifics. Here's the prompt: "This XLOOKUP returns N A for C15 even though I can see K R 215 in the Products item code column. C15 was pasted from a billing software export. What could be wrong and how do I check?" And paste the formula along with it. A good assistant will suggest checks like LEN of C15, to spot hidden spaces, ISNUMBER of C15, to spot type mismatches, and a direct test of whether C15 equals the matching cell in Products.

There's also a prompt to keep handy for lookups. It tells the AI your Excel version, your two sheets and their key columns, and the value you want. It asks for a lookup that shows "Not found" for missing keys and is robust to extra spaces. And it asks for both an XLOOKUP version and an INDEX MATCH version, with explanations. You'll find the full prompt in the lesson notes below this video.

Now, try it yourself. This takes about fifteen minutes, so pause the video and follow along. Step one. Create the Sales and Products sheets from this lesson, with ten sales rows and five products. Deliberately add one item code in Sales that isn't in Products, and one with a trailing space. Step two. Write an XLOOKUP, or INDEX MATCH if you're on older Excel, to bring in the category, with "Not found" for missing codes. Step three. Note which rows fail, and ask an AI why, using the debugging prompt. Step four. Fix the trailing-space row by wrapping the lookup value in TRIM inside your XLOOKUP. Step five. Add a second lookup that brings in the G S T rate. Then add a third column for the G S T amount on a G S T-inclusive amount. That's the amount, minus the amount divided by one plus the G S T rate. The exact formulas are in the lesson notes.

Let's recap. XLOOKUP is the modern default. It's exact match by default, works left or right, and has built-in "not found". On Excel 2016 or 2019, use INDEX MATCH, with zero as the match type. Read VLOOKUP in old files, but avoid it in new work, because inserted columns silently break it. Most N A errors are spaces, text versus number mismatches, or genuinely missing keys. And use helper columns for multi-condition lookups when colleagues need to maintain the file.
