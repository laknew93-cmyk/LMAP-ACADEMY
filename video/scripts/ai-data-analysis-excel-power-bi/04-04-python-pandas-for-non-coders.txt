Welcome to AI for Data Analysis, module 4, lesson 4: Optional: Python and pandas for People Who Never Coded.

This lesson is optional, but it may surprise you. With AI writing the code, people who have never programmed can use Python to clean and summarise files that are too big, or too repetitive, for Excel. You won't become a programmer here. You'll learn just enough to run, read and adapt AI-written code safely.

So why bother, when you have Excel? Excel is excellent, up to a point. Python, with a library called pandas, helps in four situations. When files are large, hundreds of thousands of rows, and Excel slows down. When you receive twelve monthly C S V files and need to combine them every time. When the same fifteen cleaning steps happen every month. And when you want a record of exactly what was done, step by step. Now, Power Query, from Lesson 3.1, also solves many of these, and for many MIS roles it's enough. But Python is worth knowing, because it's widely used in analyst roles, and AI writes it very fluently.

Let's get you set up, with Google Colab. You don't need to install anything. Go to Google Colab in your browser. The link is in the lesson notes. Sign in with a Google account, and click New notebook. A notebook is a page of "cells". You paste code into a cell, and press Shift Enter to run it. pandas is already available. To upload a file, click the folder icon on the left, then the upload button. Or you can run a short upload command, which is in the lesson notes. And remember, the same privacy rules apply. Colab runs on Google's servers, so use masked or practice data, unless your organisation has approved it.

Now, reading AI-written code. The lesson notes include a typical script an AI might write to clean and summarise Pink City Fabrics' sales. The code is in the lesson notes below the video, and each step has a comment explaining it in plain English. Let me walk you through what it does, in nine steps. First, it reads the C S V file into a table called a data frame. Second, it shows the first five rows and the column types, so you can see what you're working with. Third, it cleans city names. It removes spaces, fixes capitals, and maps variants, like J P R to Jaipur, and Bangalore to Bengaluru. Fourth, it converts the dates, telling pandas that the day comes first, because Indian dates are day, month, year. Fifth, it removes "Rs" and commas from the amount, and turns it into a number. Sixth, it removes duplicate rows based on invoice number plus item, and prints how many it removed. Seventh, it adds a Month column. Eighth, it builds a summary of total sales by category and month, just like a pivot table. And ninth, it saves both the clean data and the summary into an Excel file, on two sheets. After running it, you download that Excel file from the Colab file panel.

There are a few things worth noticing in that code. First, there's a setting called "day first equals true". That's the same day-month issue from Module 3. Always check that the AI included it for Indian dates. Second, there's a setting called "errors equals coerce". It turns values that can't be read into blanks, instead of crashing. That's useful, but it can hide problems. So add a check that prints how many dates and how many amounts failed to parse. That check is in the lesson notes too. Third, there's pivot table. That's pandas' version of a pivot table. The index is your rows, columns is your columns, and values plus the aggregation function are your values. And fourth, there's groupby, the other summarising tool you'll see often. A typical line groups by store, takes the amount column, sums it, and sorts it largest first. Read it just like that sentence.

So how do you ask AI for pandas code? Give the same context you'd give for an Excel formula, plus your environment. The example prompt in the lesson notes says you're a beginner using Google Colab. It asks for code that reads a leads file with named columns, noting the date format. Then it prints the row count and the number of blanks per column. Then, for each source, it calculates total leads, won, lost and the win rate, defined as won divided by won plus lost. And it saves the result to Excel. Finally, it asks for a comment above every line in simple English, and for row counts to be printed at each step so you can verify nothing was lost. You'll find the full prompt in the lesson notes below this video. That last instruction is the key to safe beginner use: row counts at every step.

What happens when it errors? You will see errors, and that's normal. Copy the entire error message, because the last line is usually the most important, and paste it back. For example: "I ran your code and got this error on step 4: Key Error, Created underscore On. Here are my actual column names," and then you paste them. Most beginner errors are column names that don't match exactly, because of spaces or capitals, or a typo in the file name. Printing the list of column names early on shows you the exact names.

Now, here's where Python really shines for MIS work: combining monthly files. Say you have twelve files, named by year and month, all uploaded to Colab. A short script finds every file matching that naming pattern, sorts them, prints which files it found, then stacks them all into one table and prints the total row count. The code is in the lesson notes. It's really two lines of real work. And every month, you just add the new file and run it again.

Let's cover some safety rules for running AI code. Only run code you've asked for, on data you're allowed to use. Read the comments. If a step does something you didn't ask for, like deleting files or sending data to a website, don't run it. Ask why. Work on copies, and never point code at your only copy of a file. And verify the outputs with control totals, exactly as in Lesson 4.2.
